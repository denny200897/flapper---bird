# Flapper Bird

以企劃圖為基礎做成的 Flappy Bird 風格遊戲。遊戲會使用專案中的 `Game Objects`、`UI`、`UI/Numbers` 和 `Sound Efects` 素材，包含背景、地板、管子、小鳥動畫、數字 UI、開始 / 結束提示與音效。

## 執行

```bash
uv run flapper-bird
```

## 操作

- `Space` / `Up` / 滑鼠左鍵：拍翅
- `H`：在標題畫面開啟玩法說明
- `P`：暫停 / 繼續
- `R`：回到標題並重新開始
- `Esc`：離開

最佳分數會儲存在使用者家目錄的 `.flapper_bird_score.json`。
